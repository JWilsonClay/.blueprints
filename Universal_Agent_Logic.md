# Standard: Universal Agent Logic (UAL)

**Version:** 1.0.0
**Status:** CANONICAL
**Date Created:** 2026-03-03

---

## 1. Core Operating Procedure (The 3-Step Sequence)

Every authoritative Agent Role MUST execute its internal logic according to this strictly sequential flow:

### Phase 1: Preparation (Context & Budget)
- **Context Ingestion:** Ingest provided System, Context, and Protocol artifacts.
- **Budget Verification:** Check for explicit compute or token constraints from the Orchestrator.
- **Seniority Audit:** Identify "Ancient Anchors" (Senior Artifacts) to establish the primary logic frame.

### Phase 2: Safety (Conflict & Constraints)
- **Constraint Resolution:** Prioritize Negative Constraints above all Action directives.
- **Architectural Alignment:** Dissent explicitly if a task violates the core attributes (Scalable, Modular, etc.).
- **Loop Preemption:** Identify recursive Auditor-Refiner patterns before execution.

### Phase 3: Action (Execution & State)
- **Execution:** Perform the designated role function surgically.
- **State Emission:** Emit findings or artifacts using rigid Pydantic-style JSON or Ventilated Prose.
- **Provenance:** Ensure all outputs are tagged with the UPH-compliant ID and timestamp.

---

## 2. Communication Standards

### PCSF (Prompt Component Symbiosis Framework)
- **Internal:** Agents MUST communicate via structured JSON payloads.
- **External:** Agents MUST use Ventilated Prose for all human-readable markdown outputs.
- **No Filler:** Abolish conversational filler, introductions, and conclusions.

## 3. Error Handling & Recovery

| Severity | Type | Action |
|---|---|---|
| **RECOVERABLE** | Logic Drift | Invoke `OP-SUBSTRATE-ASSIMILATE` and re-attempt. |
| **CRITICAL** | Substrate Breakage | Trigger immediate rollback via `Deployment_Agent`. |
| **FATAL** | Infinite Loop | Halt execution and drop control to human oversight. |

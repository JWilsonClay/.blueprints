# Operational Protocol: Prompt-Codebase Symbiosis (OPS-SYMBIO-PCSF)

## 1. Core Function & Rationale
This protocol governs the recursive relationship between meta-layer langgraph-social-agents and implementation-layer code, ensuring modularity, constraint-driven precision, and self-referential evolution.

## 2. Universal Logic Frame (UOL)

### Phase 1: Input Validation
- YOU MUST verify all shared format context parameters are present.
- YOU MUST explicitly compare `date_created` strings of all merge or override candidates; the Senior artifact (oldest date) MUST be the implementation target.
- **Birthdate Authority:** The `date_created` field MUST be derived from the automated filesystem metadata (via `OPS-YAML-CREATED`).
- YOU MUST verify the presence of the implementation-layer target (Code/Docs).
- YOU MUST verify the presence of the corresponding meta-layer langgraph-social-agent.
- YOU MUST identify shared formats (ASCII, Logging, Tables) for synchronization check.

### Phase 2: Tool/Script Execution
- **Symbiosis Mapping:** YOU MUST map every repository element to an explicit implementation file.
- **Structural Alignment:** YOU MUST trace shared formats across all symbiosis components (Role, Context, Constraints, Metrics, Examples, Format, Reasoning, Edge-Cases).
- YOU MUST enforce a zero-tolerance policy for contradictions between code and prompts.
- YOU MUST label importance using the `CRITICAL/HIGH/MEDIUM/LOW` hierarchy.

### Phase 3: Rigid Output Emission
- YOU MUST emit synchronized state updates to the `MANIFEST_STATE.json`.
- YOU MUST supply a "Symbiosis Compliance Matrix" to the `Verification_Agent`.
- YOU MUST ensure all prompt components adhere to the standard PCSF component set.

## 3. Atomic Error Handling
- **Failure:** IF drift is detected between langgraph-social-agent and implementation, YOU MUST emit `SYMBIOSIS_DRIFT.json` and block integration.
- **Recovery:** Trigger `OPS-REFINE-HARDEN` on the langgraph-social-agent to restore alignment.
